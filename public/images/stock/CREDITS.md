# Stock Image Credits

All stock images in this folder must have an entry below with source, license, and credit.

## Format

```
### <filename.jpg>

- **Source**: <URL>
- **Author**: <Name>
- **License**: <Unsplash License | Pexels License | CC0 | CC BY 4.0 | ...>
- **Used on**: <page paths>
- **Notes** (optional): <crop / edits / etc.>
```
